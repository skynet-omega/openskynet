# SKYNET Context Base

## Mision

`Skynet` no existe para optimizar un chatbot con tools.
Existe para buscar un salto arquitectonico real hacia una cognicion mas continua, causal y autonoma.

## Rol de cada capa

- `OpenSkyNet`: plataforma de supervision, memoria, benchmark, gateway, tooling, evaluacion
- `Skynet`: nucleo experimental que debe ganar continuidad, programa propio, metabolismo y automejora no trivial

## Linea experimental destilada

Las lineas que sobrevivieron de los experimentos antiguos son:

- memoria selectiva con reescritura local
- decision como bifurcacion y estabilizacion
- metabolismo cognitivo real
- nucleo dual o bicameral
- agenda cientifica endogena

Las lineas que no deben volver como centro:

- fisica ornamental sin cierre conductual
- modulos exoticos sin mecanismo verificable
- complejidad narrativa que no cambie conducta futura

## Regla de oro

Cada ciclo autonomo debe dejar al menos una de estas cosas:

- un artefacto nuevo ejecutable
- un benchmark
- una regla causal verificada
- un criterio de kill

Si no deja ninguna, el ciclo fue debil.

## Blanco actual

El blanco actual no es agregar mas coordinacion.
Es materializar un artefacto ejecutable del nucleo que pueda ser validado en el siguiente ciclo.

## Recordatorio epistemico

No confundir:

- continuidad de texto
- memoria documental
- agencia real

La prueba importante es si el sistema cambia conducta futura de forma estable y verificable.
